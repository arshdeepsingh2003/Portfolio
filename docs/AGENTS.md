# AI Coding Agent Instructions

## Required stack
- Frontend: React + Vite + TypeScript.
- Backend: Python + FastAPI, only for approved server-side features.
- Styling: Tailwind CSS.
- Validation: Pydantic where API input exists.
- **Database: none. Do not add or configure a database.**

## Workflow
Read relevant files in `docs/` before making changes. Work on one phase in `docs/TASKS.md` at a time. Inspect the repository, explain the plan and acceptance criteria, implement only the approved phase, run applicable checks, update task/memory documentation, and wait for explicit approval before starting the next phase.

## Architecture and security
Keep project and skill content in local data files. React must not connect to a database. Do not add a database, ORM, persistent storage, admin panel, or authentication. Do not implement a contact form unless requested; direct contact links are the default. Keep secrets out of frontend bundles.

## Content and design
Follow the documented palette. Use genuine approved project details and assets. Keep Web Projects and Data Analytics separate. Do not invent metrics, testimonials, or URLs.

## Validation
Run available frontend checks/build and backend checks if endpoints exist. Never claim checks passed unless they were run. Ask before making consequential decisions when requirements are unclear.
