# Design Notes

This is the short design file listed in the supplied editor screenshot. The canonical detailed specification is `DESIGN_SYSTEM.md`.

## Visual direction
- Editorial and personal, not a generic SaaS dashboard.
- Warm ivory `#F5F0E6`, forest green `#173C32`, muted plum `#8B7188`, charcoal `#252824`.
- Serif display headings, clean sans-serif body text, small monospace labels.
- Subtle paper-like texture and occasional hand-drawn underline/arrow accents.
- Real project screenshots and charts should carry the visual interest.

## Page sections
1. Header/navigation
2. Hero
3. About
4. Skills
5. Web development projects
6. Data Analytics projects
7. Contact/footer

## Avoid
- Copying the reference site's colors or exact layout.
- Overusing gradients, glow effects, glassmorphism, floating blobs, or excessive animation.
- Fake charts, fake testimonials, stock imagery pretending to be project work, or invented statistics.
- Tiny low-contrast text and decorative elements that compete with content.

## Interaction
Keep hover states restrained, focus states visible, and motion optional. Respect reduced-motion preferences.
